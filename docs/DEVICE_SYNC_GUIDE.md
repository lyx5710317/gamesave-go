# 两台设备连接与存档同步教程

本教程适用于 GameSave Go Windows v1.1.1。设备同步是两台电脑之间的配对和传输；“云备份 → 浏览云端／恢复”是另一项功能，不能代替设备配对。首次操作请只用测试文件，不要直接拿唯一一份真实游戏存档试验。

## 开始前

1. 两台电脑都从本仓库的 [正式 Release](https://github.com/lyx5710317/gamesave-go/releases/tag/v1.1.1) 安装 GameSave Go 并启动。建议两边都使用 v1.1.1。
2. 先在两台电脑各自准备一个**独立的测试存档文件夹**，不要指向真实游戏目录。在其中一台放一个可辨认内容的测试文件，另一台使用空的测试文件夹。
3. 在两台电脑的“游戏”页面添加同一个测试游戏，并分别核对游戏详情中显示的**本机存档路径**。路径不需要相同，但必须分别指向各自的测试文件夹。先做好这一步，再批准配对请求，因为配对后可能开始同步。
4. 保留原文件的独立副本。同步或恢复前关闭正在运行的游戏，避免游戏与同步程序同时写入。

## 两台电脑在同一网络

1. 在电脑 A 的首页点击“＋添加设备”，进入“设备”页面，保持“同一网络”标签。
2. 在发现列表中找到电脑 B，核对设备名称后点击“配对”。
3. 到电脑 B 的 GameSave Go 中查看配对请求，确认是自己的电脑后点击“批准”。
4. 回到“设备”页面，确认对方显示为“在线”。然后打开测试游戏详情，点击“立即同步”；在“活动”页面查看结果，并到另一台电脑的测试文件夹核对文件内容。**显示在线或提示已发送配对请求，都不等于文件已经同步完成。**

如果列表中没有电脑 B，可在 B 上查看当前局域网 IP，在 A 的“按 IP 添加”处填写这个 IP 和端口（默认 `8383`），点击“发送配对请求”，再到 B 批准。两台电脑应在能互通的局域网内；如果 Windows 防火墙询问是否允许程序访问专用网络，只允许你信任的网络。不要为了配对关闭防火墙，也不要把 `8383` 端口直接暴露到公网。

## 两台电脑不在同一网络

1. 两台电脑都打开首页“＋添加设备”→“通过互联网”。
2. 在电脑 A 生成或填写一个房间码，点击“加入房间”；在电脑 B 输入**完全相同**的房间码并加入。房间码只发给你信任的另一台设备。
3. 等待页面显示已连接，并出现对方设备。在其中一台点击“配对”，到另一台批准。
4. 确认“设备”页面显示对方在线后，按上节的方法对测试游戏执行“立即同步”，查看“活动”结果并核对两边测试文件。中继初次唤醒或重新连接可能需要等待；可以使用页面的“测试中继”检查是否可达。

**隐私提醒：**跨网络中继不是端到端加密。传输连接受到保护，但中继服务的运营者可能接触传输中的存档内容；敏感存档请先评估这一点，或使用可信的自建中继。

## 路径、冲突与正式存档

- 每台电脑的游戏安装位置、用户名和盘符可能不同。若提示“请在另一台设备上设置此游戏的实际存档文件夹，或添加路径转换”，先在**对应的那台电脑**核对游戏详情中的存档路径；必要时到“设置 → 高级 → 跨平台路径映射”配置映射，再重新同步。不要把提示中的路径机械复制到另一台电脑。
- 若出现存档冲突，先比较两边内容；不确定时选择“保留双方”，之后再决定使用哪个版本。不要仅凭修改时间选择覆盖，也不要在游戏运行中处理冲突。
- 测试文件能从 A 到 B、也能从 B 到 A，且内容一致后，再把真实游戏的存档路径分别配置到两台电脑。先另行备份真实存档，再开始首次同步。
- 自动同步可在游戏详情中设置；即便打开自动同步，仍应查看“活动”中的失败或冲突提示，并确认另一台电脑上的实际文件。

## 常见问题

| 现象 | 先检查什么 |
| --- | --- |
| 找不到另一台电脑 | 两边程序是否正在运行、是否位于可互通的同一局域网；尝试按 IP 添加。 |
| 显示离线或连接超时 | 检查对方是否开机、局域网 IP 是否改变、防火墙是否允许专用网络访问；跨网络时检查两边是否加入同一房间并使用“测试中继”。 |
| 已配对却没有文件 | 核对两边游戏的实际存档路径，点击“立即同步”，再查看“活动”中的具体结果。不要只根据“在线”判断同步成功。 |
| 提示路径映射或冲突 | 先停止操作并保存两边文件的副本；按上节核对路径或选择保留双方。 |
| 只在“浏览云端”看到快照 | 那是云备份，不是设备同步。云端快照需要单独验证或恢复；不要期待它自动成为另一台电脑的当前存档。 |

需要求助时，可以提供软件版本、连接方式（同一网络／中继）、“活动”里的非敏感错误提示；请遮盖用户名、局域网以外的地址、邮箱、房间码和存档内容，不要发送密码或令牌。
